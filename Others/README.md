# Others / Quarantine & Non-Runtime Reference

This directory contains quarantined non-runtime artifacts, previous development milestone scripts, raw design assets, and historical reference material that are **not** required for the production runtime of the OPICOC platform.

## Contents

- **`milestone-scripts/`**: Historical milestone verification scripts (`verify-phase09.ts` through `verify-phase15.ts`) used during previous development phases.
- **`raw-base-images/`**: Uncompressed source screenshots and PNG assets from early design mockups (preserved for visual reference, not served in production).
